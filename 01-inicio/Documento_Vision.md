# 1. Documento de Visión - Proyecto AgroVerde S.A.C.

## Información General del Proyecto
- **Curso:** Modelado y Desarrollo de Aplicaciones (CIIN1322P)[cite: 57]
- **Tema:** Proceso Unificado RUP y UML (Tema N° 6)[cite: 57]
- **Título de la experiencia:** Planificación iterativa con RUP + coherencia de artefactos UML por fase[cite: 57]

## Borrador del Documento de Visión (Procedimiento - Paso 1)
| Sección | Descripción para AgroVerde S.A.C. |
| :--- | :--- |
| **Problema** | El registro manual de riegos dificulta controlar programación, consumo e incidencias[cite: 58]. |
| **Propuesta de valor** | Centralizar información de cultivos, parcelas y riegos para mejorar trazabilidad[cite: 58]. |
| **Objetivo** | Permitir programar riegos y registrar su ejecución con validaciones y alertas[cite: 58]. |
| **Interesados** | Agricultores, supervisores agrícolas, administración y soporte[cite: 58]. |
| **Alcance incluido** | Registrar cultivos, programar riegos, validar agua, consultar reportes[cite: 58]. |
| **Fuera del alcance** | Control físico automatizado de válvulas en la primera versión[cite: 58]. |
| **Restricciones** | Conectividad variable en campo; acceso según rol; datos constantes[cite: 58]. |
| **Criterio de éxito** | Los usuarios completan los escenarios prioritarios y validan sus resultados[cite: 58]. |
