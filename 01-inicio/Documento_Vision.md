# 1. Documento de Visión - Proyecto AgroVerde S.A.C.

## Información General del Proyecto
- **Curso:** Modelado y Desarrollo de Aplicaciones (CIIN1322P)
- **Tema:** Proceso Unificado RUP y UML (Tema N° 6)
- **Título de la experiencia:** Planificación iterativa con RUP + coherencia de artefactos UML por fase

## Borrador del Documento de Visión (Procedimiento - Paso 1)
| Sección | Descripción para AgroVerde S.A.C. |
| :--- | :--- |
| **Problema** | El registro manual de riegos dificulta controlar programación, consumo e incidencias. |
| **Propuesta de valor** | Centralizar información de cultivos, parcelas y riegos para mejorar trazabilidad. |
| **Objetivo** | Permitir programar riegos y registrar su ejecución con validaciones y alertas. |
| **Interesados** | Agricultores, supervisores agrícolas, administración y soporte. |
| **Alcance incluido** | Registrar cultivos, programar riegos, validar agua, consultar reportes. |
| **Fuera del alcance** | Control físico automatizado de válvulas en la primera versión. |
| **Restricciones** | Conectividad variable en campo; acceso según rol; datos constantes. |
| **Criterio de éxito** | Los usuarios completan los escenarios prioritarios y validan sus resultados. |
